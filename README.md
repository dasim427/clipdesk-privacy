# Clip Desk — политика конфиденциальности

Публикация страницы политики для расширения Clip Desk.

Живая страница: https://dasim427.github.io/clipdesk-privacy/

Содержимое — файл `index.html`, английская и русская версии на одной странице.
Исходник лежит в основном репозитории проекта, в `store/index.html`.
При изменении политики нужно обновить оба места.

Рядом лежит `uninstall.html` — страница, которую Chrome открывает после
удаления расширения (`setUninstallURL` в `src/config.ts`). Её исходник —
`store/uninstall.html` там же.

Пустой `.nojekyll` отключает обработку Jekyll: без него готовый HTML
заворачивался в тему по умолчанию, и страница открывалась с чужим
заголовком и чужими стилями.

Ссылка на эту страницу указана в карточке расширения в Chrome Web Store,
поэтому адрес менять нельзя.
